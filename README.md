# Piccoli Passi

App per genitori: le tappe del primo anno del bambino mese per mese, diario (poppate, pannolini, sonno), crescita, vaccini e guide pratiche. Dati solo sul telefono.

- Stack: Vite + JavaScript + Capacitor (Android), come Orto Mio e Cucina Mia
- ID app: `it.devori.piccolipassi`
- `npm install && npm run dev` per provarla nel browser
- GitHub Actions: APK di prova a ogni push, AAB firmato da lanciare a mano (stessi Secrets delle altre app)

Anteprima web: https://mirkoori.github.io/primi-passi/
